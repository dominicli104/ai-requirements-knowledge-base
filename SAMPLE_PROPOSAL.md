# Northstar AI Marketplace — Fictional Sample Proposal

> FICTIONAL SAMPLE ONLY — NOT AN ACTUAL CLIENT PROPOSAL.

This document is fabricated solely for a public Business Analyst portfolio. All 18 requirements below correspond one-to-one to the sample register.

## Section 1.1 — Account Management
**DEMO-REQ-001** — An organisation administrator shall be able to create a user account with a unique email address.

## Section 1.2 — Account Management
**DEMO-REQ-002** — Only user accounts with Active status shall be permitted to sign in.

## Section 1.3 — Account Management
**DEMO-REQ-003** — An organisation administrator shall be able to deactivate an existing user account.

## Section 2.1 — Roles & Permissions
**DEMO-REQ-004** — An organisation administrator shall be able to create and edit roles and their permitted actions.

## Section 2.2 — Roles & Permissions
**DEMO-REQ-005** — Users shall not access information belonging to another organisation.

## Section 3.1 — Agent Catalogue
**DEMO-REQ-006** — Users shall be able to filter available agents by category and keyword.

## Section 3.2 — Agent Catalogue
**DEMO-REQ-007** — Each catalogue entry shall display its agent name, short description and category.

## Section 4.1 — Credit Wallet
**DEMO-REQ-008** — The portal shall display purchased and promotional credit balances separately.

## Section 4.2 — Credit Wallet
**DEMO-REQ-009** — The portal shall display a combined available credit balance calculated from purchased and promotional credits.

## Section 4.3 — Credit Wallet
**DEMO-REQ-010** — An authorised administrator shall be able to grant sample promotional credits to a selected organisation.

## Section 4.4 — Credit Wallet
**DEMO-REQ-011** — The system shall record each administrator-issued credit adjustment in a transaction log.

## Section 5.1 — Usage Metering
**DEMO-REQ-012** — An organisation administrator shall be able to view AI request usage totals for a selected reporting period.

## Section 5.2 — Usage Metering
**DEMO-REQ-013** — An authorised administrator shall be able to assign a monthly usage quota to a user.

## Section 6.1 — Audit & Logs
**DEMO-REQ-014** — An authorised auditor shall be able to search administrative operation logs by date and action type.

## Section 6.2 — Audit & Logs
**DEMO-REQ-015** — Every log record shall include an event timestamp, actor and action.

## Section 7.1 — Wishlist
**DEMO-REQ-016** — The portal could allow users to save favourite agents for quick access.

## Section 7.2 — Wishlist
**DEMO-REQ-017** — The portal could support a comparison view for up to three agents.

## Section 8.1 — Non-Functional
**DEMO-REQ-018** — The interface shall communicate validation errors beside the affected form field.
